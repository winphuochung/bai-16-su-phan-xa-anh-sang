# Web/app học tập — Khoa học tự nhiên 7, Bài 16

**Bài 16: Sự phản xạ ánh sáng** (Chương V: Ánh sáng)
Môn Khoa học tự nhiên 7 — Chương trình GDPT 2018, sách Kết nối tri thức với cuộc sống (SGK trang 78–81).

Giáo viên: Lê Văn Thắng — Trường TH và THCS Phước Hưng, xã Nhơn Hội, tỉnh An Giang.

## Nội dung

Web/app học tập 6 phần: Khởi động, Khám phá, Mô phỏng, Sơ đồ tư duy, Luyện tập (10 câu trắc nghiệm tự chấm), Vận dụng.

Mô phỏng (SVG nội tuyến, tương tác): tia sáng tới gương phẳng — kéo thanh trượt đổi góc tới 0°–80°, tia phản xạ đổi theo và luôn đối xứng với tia tới qua pháp tuyến (i' = i); chuyển sang mặt gồ ghề để thấy phản xạ khuếch tán: 3 tia tới song song phản xạ theo mọi hướng.

Khóa đáp án trắc nghiệm: 1A 2B 3B 4C 5D 6A 7B 8C 9B 10D.

## Cách dùng

- Mở file `index.html` bằng trình duyệt bất kì (không cần máy chủ).
- Học sinh đăng nhập bằng Họ tên + Lớp, học 6 phần, làm 10 câu trắc nghiệm rồi nộp bài.
- Điểm tự động lưu về Google Sheets của giáo viên (qua Apps Script Web App, chạy bằng tài khoản giáo viên).

## File trong thư mục

- `index.html` — web/app hoàn chỉnh, tự chứa (hình ảnh nhúng base64), đã gắn gửi điểm về Google Sheets.
- `Web_Hoc_Tap_KHTN7_Bai16.md` — bản sao toàn bộ mã nguồn kèm khóa đáp án.
- `Code.gs` — mã Apps Script Web App ghi điểm vào Google Sheets (tab KetQua).
- `assets-flow/` — 3 ảnh nền JPG (hero, nền chính, nền đăng nhập) + logo cá nhân thầy Lê Văn Thắng (PNG trong suốt).
